Chapitre 07 6 fiches

Structures Conditionnelles

if, else if, switch — choisir le bon chemin selon la valeur

Les 6 structures à connaître
Le chapitre couvre bien tous les chemins de décision : les fiches détaillées restent disponibles via le bouton des fiches masquées.
ifExécute un bloc si la condition est vraie.
if (condition) { ... }
if / elseChoisit entre deux chemins.
if (...) { ... } else { ... }
else ifTeste plusieurs conditions successives.
if (...) { } else if (...) { }
Conditions composéesCombine plusieurs tests avec && et ||.
switchChoisit un cas selon une valeur donnée.
switch (valeur) { ... }
switch moderneÉcriture moderne avec case ... -> et expressions.
